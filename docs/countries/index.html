This directory groups the current project dataset by EU member state. It excludes independent MEPs and is intended as a research index, not a list of findings or allegations.

For current parliamentary information, consult the European Parliament full list of Members, which also provides national-party and activity details.

Before treating any entry as evidence of a political position, read the methodology and check the underlying source record.
