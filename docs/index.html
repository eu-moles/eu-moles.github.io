EU MEPs & Russian Moles

A source-first research directory for examining pro-Kremlin positions in the European Parliament.

What this project is

EU MEPs & Russian Moles is a research-oriented directory for documenting verifiable public positions, votes, affiliations, and reporting relevant to pro-Kremlin influence in the European Parliament.

The term “moles” is the project name, not a finding about any individual. A listing must never be treated as proof of covert activity. Every substantive claim should link to a primary record or a reputable published investigation.

Start with the directory

Browse the country directory to see the current national-party and seat-count dataset. It is a starting point for research—not a list of accusations.

Research standard

  • Separate documented facts from analysis and allegations.
  • Attribute every claim to a source, date, and author or institution.
  • State uncertainty, corrections, and conflicts of interest plainly.
  • Do not infer a person’s position from nationality, party membership, or association alone.

Read the methodology before using or contributing to the directory.
